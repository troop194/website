This project is designed to be a simple, but well made landing page for the public to find Rocky River Troop 194. Because of this, there are some design guidelines that I need you to follow:

Design Guidelines
- Do not excessively use left-borders with cards and navigation
- No not use heavily stylistic fonts, and use only reasonable regular feeling fonts
- The main conversion goal is to send the user to the beascout.org page for Troop 194, where they can immediately join the troop
- SEO is an important, main factor for this page - keywords that are important to the page are: Troop 194, Rocky River, Rocky River UMC, Cleveland, Lakewood, Scouting, Scouting America, Scouts BSA, Lake Erie Council, Greater Cleveland Area, among other keywords that you might decide on
- Images may come from the git ignored wix_files/
- The website should feel well made, but not over-engineered - avoid complex animations and scroll behaviors
- Avoid adding frameworks w/o explicit suggestion, this should be a plain HTML project for performance and non-technical user interaction
